# 🚗 AI-Based Driver Fatigue Monitoring System

## 📌 Overview

This project focuses on detecting driver fatigue using an Artificial Neural Network (ANN) built from scratch using NumPy.
The goal is to identify patterns in input data that indicate whether a driver is alert or fatigued.

Driver fatigue is a major cause of road accidents, and this system aims to contribute toward safer driving using AI-based solutions.

---

## 🎯 Objectives

* Build a basic understanding of Artificial Neural Networks (ANN)
* Implement a neural network from scratch without using deep learning libraries
* Apply the model to a fatigue detection problem
* Strengthen practical knowledge of machine learning concepts

---

## 📊 How the Model Works

1. Input data is provided to the neural network
2. Inputs are multiplied with weights and bias is added
3. Activation function is applied
4. Output is generated (fatigue / not fatigue)

This is a simplified ANN model designed for learning and demonstration purposes.
